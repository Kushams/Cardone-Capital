## Fidelity notes (read before relying on this archive)

- Each message is a **verbatim transcription** of the message as rendered in Zoho: headers (From / To / Reply-To / Date / Subject), complete body, signature blocks, link URLs, and image descriptions (alt text + position).
- **No .eml files**: Zoho's "Save as EML" was attempted for the first messages; the browser could not save download files, so no .eml exists. The transcriptions are the archive record.
- **Images**: Zoho had external images blocked during extraction, so images are recorded by their alt text, size and position, not embedded.
- **Repeated legal footers** are stored verbatim ONCE in `footers.md` and cited per message (Footer A / B / C / D, plus the navy banner block). A message + its cited footer together reproduce the email exactly as received.
- Two long marketing sends that were verified word-for-word duplicates of an earlier send cross-reference that send's body (differences — date, subject, tracking link — are recorded in their own entries). All other messages are written out in full.
- Side effect of reading: opening messages marked some as read (Spam unread 46→40, Notification unread 4→3; one Newsletter message was accidentally toggled back to unread). Nothing was deleted, moved, replied to, forwarded, or signed out.
